Setup, Configuration, And Testing

The project is packaged with setuptools, uses litellm for model transport, and can run through the console script or python -m src.main.

1. Install

python -m venv .venv
.venv\Scripts\activate
pip install -e .[tui]

2. Configure

LLM_PROVIDER=ollama_chat
LLM_MODEL=gemma4:e4b
LLM_API_BASE=http://localhost:11434

3. Validate

python -m src.main doctor --cwd .
python -m src.main agent-context --cwd .
python -m unittest discover -s tests -v

4. Run

python -m src.main agent-chat --cwd .
python -m src.main agent-tui --cwd .
python -m src.main agent "Summarize the repo" --cwd .

Permission defaults

CLI write and shell permissions default to enabled unless CLAW_NO_WRITE=1 or CLAW_NO_SHELL=1 is set. Use --no-write and --no-shell for read-only runs. Destructive shell commands still require --unsafe.

Persistence locations

Agent sessions are stored under .port_sessions/agent, and scratchpads under .port_sessions/scratchpad. Resume rebuilds from stored messages, context dictionaries, and runtime state.

Model transport

The supported backend is litellm. Provider and endpoint settings are normalized from LLM_PROVIDER, LLM_MODEL, LLM_API_BASE, provider API keys, and LLM_API_KEY.
